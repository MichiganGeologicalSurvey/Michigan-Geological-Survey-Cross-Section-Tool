# Michigan Geological Survey: Cross-Section Tool Box for ArcGIS Pro
## **SAMPLE PROJECT**

We have provided a sample project created from Wellogic water well data as an example of what a completed project, the outputs, and potential layouts look like. This project was created using the Project Creation Tool and cross-section files were produced with many of the MGS Cross-Section Tools. The project can be found at the Google Drive link [here](https://drive.google.com/file/d/1WMJRadJNdZlycMHBqlAxa5HTneLmD_mk/view?usp=sharing) (Approximate size: 63mb)
